UNIPREP 2 UGEL — ACTIVAR UNI CON IA EN VERCEL
Versión 2026.20.1 Harmony Clean

Uni ya está integrada en la aplicación. La clave de OpenAI se utiliza únicamente
en la función privada api/tutor.js: nunca se coloca en index.html, en el JavaScript
del navegador, en Supabase, en GitHub ni en localStorage.

1. PREPARAR OPENAI

1. Crea o abre tu proyecto de API de OpenAI.
2. Configura facturación y un límite de gasto apropiado para el piloto.
3. Crea una clave secreta del proyecto. No la compartas ni la incluyas en el informe.
4. Para el presupuesto de S/250 por tres meses, empieza con gpt-5.6-luna y revisa
   el consumo semanal. La aplicación muestra una estimación, no una factura oficial.

2. PREPARAR SUPABASE

Ejecuta en SQL Editor, en este orden:

1. SUPABASE_UGEL_RANKING_FOTOS.sql, si aún no se aplicó.
2. SUPABASE_UGEL_EVOLUCION.sql.

La segunda migración crea preferencias, paquetes IA, resultados vocacionales,
feedback y eventos de uso. Todas las tablas nuevas tienen Row Level Security.

3. CONFIGURAR VERCEL

En Project > Settings > Environment Variables agrega para Production, Preview y
Development:

OPENAI_API_KEY              clave privada del proyecto OpenAI
OPENAI_MODEL                gpt-5.6-luna
SUPABASE_URL                la URL del proyecto usada por js/supabase.js
SUPABASE_PUBLISHABLE_KEY    la clave publicable usada por la web

La eliminación del Dock rápido no necesita ninguna variable adicional. Estas cuatro
variables son para activar el Tutor IA y validar la sesión del alumno.

Guarda y vuelve a desplegar el proyecto. ChatGPT Plus/Pro y la API de OpenAI se
facturan por separado.

4. PRUEBA TÉCNICA

Abre https://TU-DOMINIO.vercel.app/api/tutor
Debe responder con available:true, openai:true, supabase:true y anunciar chat y
study_pack. La respuesta nunca muestra las claves.

Después, con una cuenta de demostración:

1. Haz una consulta libre de texto.
2. Adjunta una foto pequeña de un ejercicio y pide orientación.
3. Prueba “Solo pista” para confirmar que no revela directamente la respuesta.
4. Genera un espacio de estudio con el temario integrado.
5. Prueba un PDF o imagen menor de 2.4 MB.
6. En “Preguntar sobre el material”, confirma que aparece seleccionado “Mi material”.
7. Cierra sesión, vuelve a ingresar y comprueba fondos y preferencias.
8. Revisa el panel de presupuesto de Uni.

PROTECCIONES INCLUIDAS

- Solo usuarios con sesión válida de Supabase pueden consultar la API.
- Hay control temporal de solicitudes por usuario.
- Se envían como máximo los últimos ocho mensajes relevantes.
- Las respuestas usan store:false.
- El identificador de seguridad enviado al modelo es anónimo.
- La imagen del chat se comprime y se utiliza solo para esa consulta.
- Los archivos tienen validación de tipo y tamaño en navegador y servidor.
- El archivo original no se guarda en Supabase.
- El contenido subido se trata como material no confiable y no puede cambiar
  las reglas del sistema.
- Si la API falla, Uni ofrece una guía local y el resto de la plataforma continúa.

CONTROL DEL PRESUPUESTO

No existe una IA comercial realmente infinita por un pago fijo. El alumno puede
ver una experiencia sin contador ni bloqueo rígido, pero el propietario debe usar
alertas y límites del proyecto, revisar el consumo y evitar adjuntar archivos enormes.
La tarjeta de Uni calcula una aproximación local con el modelo configurado; el dato
definitivo siempre es el panel de facturación del proveedor.
