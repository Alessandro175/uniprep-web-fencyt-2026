UNIPREP 2 UGEL — PAQUETE WEB 2026.21 · HARMONY COMFORT

Este paquete contiene la versión web lista para publicar en Vercel.
No incluye Android, Gradle, Capacitor ni archivos para Play Store.

CÓMO ABRIRLO PARA UNA DEMOSTRACIÓN
1. Abre esta carpeta en Visual Studio Code.
2. Abre index.html con la extensión Live Server.
3. No abras index.html con doble clic: el navegador puede bloquear la lectura de JSON
   cuando la aplicación no se ejecuta desde un servidor local.

QUÉ NECESITA INTERNET
- Inicio de sesión, preferencias, puntajes, foto, resultados y ranking usan Supabase.
- Los recursos enlazados de Google Drive necesitan conexión.
- Las respuestas reales de Uni necesitan OPENAI_API_KEY en Vercel.
- Si la IA no está disponible, se conserva una guía académica local de respaldo.

LO PRINCIPAL DE LA VERSIÓN 2026.21
- El modo claro fue reconstruido de forma integral: ya no usa blanco puro ni deja
  módulos oscuros mezclados. Emplea fondos azulados suaves, superficies con niveles,
  sombras ligeras y texto de alto contraste para estudiar durante más tiempo.
- La paleta personalizada también se adapta al modo claro. Conserva la identidad de
  los colores elegidos y crea automáticamente versiones cómodas para fondo, barras,
  banner, tarjetas, controles y bordes.
- Inicio visual sin destellos: UniPrep aplica el modo guardado antes de dibujar la
  interfaz, evitando el salto oscuro/claro al recargar.
- Tutor IA, orientación vocacional, prácticas, simulacros, cursos, fórmulas, ranking,
  agenda, ventanas, autenticación y personalizador comparten el mismo lenguaje claro.
- Controles, focos, selección de texto, estados correctos/incorrectos y contraste
  reforzado fueron ajustados para mantener legibilidad y comodidad.
- El personalizador ahora recolorea toda la interfaz: barras, navegación, banner
  del Tutor, tarjetas principales, tarjetas internas, botones, brillos y bordes.
- Seis combinaciones profesionales y sincronización automática mantienen una
  armonía visual incluso cuando el alumno cambia fondo o acentos.
- Vista previa completa y protección de contraste antes de aplicar el diseño.
- Centro de Comandos global con búsqueda de módulos, 21 cursos, Tutor IA,
  simulacros, personalización y acciones. Se abre con Ctrl/⌘ + K.
- Buscador superior conectado al Centro de Comandos; navegación con flechas y Enter.
- Terminal UniPrep funcional con comandos help, status, go, hacker, focus, exam,
  quality y clear. Se abre con Ctrl/⌘ + `.
- Modo Hacker opcional con interfaz verde, HUD, scanlines y lluvia de código.
- Cabina de concentración global con bloques de 15, 25 y 45 minutos, pausa,
  progreso y notificación al completar la misión.
- La antigua barra flotante inferior fue retirada y no vuelve a aparecer.
- Rendimiento Auto, Ahorro, Fluido y Ultra; Auto analiza capacidad del dispositivo,
  ahorro de datos y preferencia de movimiento reducido.
- Animaciones de entrada, transición entre módulos, iluminación reactiva, pulso de
  datos, respuesta táctil y sonido suave opcional.
- Panel de misión con hora del dispositivo, estado de red, disponibilidad de IA y
  calidad visual activa.
- Todos los nuevos controles Hyperdrive aparecen en Fondos y apariencia y sus
  preferencias se guardan localmente y se sincronizan por cuenta con Supabase.
- Se conservan las 36 mejoras de la versión Evolución: Tutor educativo libre,
  dictado, foto, materiales, personalización minuciosa, orientación mejorada,
  nuevos simulacros, ranking por periodos/regiones y perfil con fotografía.

INSTALACIÓN OBLIGATORIA
1. Si todavía no se ejecutó, aplica SUPABASE_UGEL_RANKING_FOTOS.sql en Supabase.
2. Aplica después SUPABASE_UGEL_EVOLUCION.sql.
3. Sigue CONFIGURAR_TUTOR_IA.txt para las variables privadas de Vercel.
4. Vuelve a desplegar el proyecto y realiza las pruebas de PUBLICAR_2026.21.txt.

SEGURIDAD
- OPENAI_API_KEY nunca se coloca en HTML, JavaScript del navegador, Supabase,
  GitHub, capturas, videos ni informes.
- El archivo original que usa el alumno no se almacena en Supabase; solamente
  puede guardarse el paquete de estudio generado.
- Cada tabla nueva tiene Row Level Security para que un alumno acceda solo a sus datos.
- “Sin límite visible para el alumno” no significa costo infinito: el consumo real
  depende de los tokens y archivos procesados por la API.
